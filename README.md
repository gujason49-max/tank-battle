# 坦克大战 · Tank Battle

一个纯 HTML + Canvas 实现的网页坦克大战游戏，单文件即可运行，无任何依赖。

## 玩法

- 操控绿色坦克，消灭一波波来袭的敌军坦克，保护地图底部的基地（金色旗帜）。
- 基地被摧毁会损失一条生命；每局共 3 条生命。
- 波次越高，敌人越多、越强（更强的敌人需要 2 发子弹）。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` 或方向键 | 移动坦克 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |

## 元素说明

| 元素 | 说明 |
| --- | --- |
| 🧱 棕色砖块 | 可被子弹摧毁 |
| ⬜ 银色钢块 | 无法被摧毁 |
| 🌊 蓝色水面 | 坦克与子弹均无法通过 |
| 🌲 绿色树林 | 遮挡视野，但可通过 |
| 🛡 能量块 | 拾取获得护盾 / 加速射击 / 额外生命 / 四向齐射 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 技术要点

- 纯原生 JavaScript + Canvas 2D，无框架。
- 敌人 AI：加权寻路（向玩家方向 + 随机游走 + 规避障碍），视线检测后开火。
- 程序化生成关卡（砖块、钢块、水面、树林随机分布，保留出生区与基地安全区）。
- Web Audio API 合成音效，粒子爆炸特效与屏幕震动。
